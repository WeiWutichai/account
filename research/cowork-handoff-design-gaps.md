## A. เพิ่มหน้าที่ขาด (6 หน้า)
1. **FA1 ทะเบียนทรัพย์สิน + ค่าเสื่อมรายเดือน** (FA-01, สูตร DEP) — รายการทรัพย์สิน, หมวด, วิธีเส้นตรง, เฉลี่ยตามวันเดือนแรก/สุดท้าย, ปุ่ม "คำนวณค่าเสื่อม พ.ย." + ตัวอย่างการลงบัญชี, จำหน่าย (P2 แสดงเป็นปิดไว้)
2. **P4 ใบลดหนี้/เพิ่มหนี้ฝั่งซื้อ (CNR/DNR)** (PU-05) — อ้างอิงบิลซื้อเดิม, เลขใบลดหนี้ของผู้ขาย, มูลค่าเดิม/ที่ถูกต้อง/ผลต่าง, กลับภาษีซื้อ
3. **S7 ใบแจ้งหนี้เงินมัดจำ + ตัดมัดจำ** (CA-03, invoice_kind deposit/final) — ฝั่งลูกค้า และเงินมัดจำจ่ายผู้ขาย
4. **R3 รายงานตรวจความถูกต้อง** (TX-03, GL integrity) — เอกสารเทียบ GL, รายงานภาษีเทียบ GL, ลูกหนี้/เจ้าหนี้เทียบบัญชีคุม
5. **G5 เชื่อมต่อ MCP / OAuth client** — รายการ client, scopes, MCP เขียนได้แค่ร่าง, เพิกถอน
6. **G6 ตั้งค่าเอกสาร** — รูปแบบเลขเอกสารหลาย prefix/รีเซ็ต/ตามสาขา, ประเภทเอกสาร (posts_gl), ช่องข้อมูลเพิ่มเติม, กฎแปลงเอกสาร + ปิดค้าง, การปิดบังข้อมูล PDPA

ส่วนที่ควรเติมในหน้าเดิม: ฟอร์ม PO / PR (P1), ไฟล์ RD Prep ภ.ง.ด.3/53 (T1), งวดที่ 13 + ดูตัวอย่างรายการปิดปี (B5)
เพิ่มหน้าใหม่ลง Sidebar และ `project/compat.json`

## B. แก้ข้อมูลไม่ตรงกัน
1. รหัสบัญชีลูกหนี้: ScreenInvoice/CreditNote ใช้ 1130100 แต่ ScreenReceipt ใช้ 1200100 → ใช้ 1130100 ทุกหน้า
2. กำหนดยื่นภาษี: ใช้เกณฑ์ยื่นออนไลน์ทั้งหมด (ภ.พ.30 วันที่ 23, ภ.ง.ด.3/53 วันที่ 15) — แก้ ScreenExpense ("7 ธ.ค." → "15 ธ.ค.") และ Main ("15 พ.ย." → "23 พ.ย.")
3. ScreenPeriodClose: ต.ค. "ปิดโดย … 20/11" เป็นวันในอนาคต (วันนี้ในแบบร่าง 9 พ.ย.) → เปลี่ยนเป็นวันก่อน 9/11
