## 1. สรุป

- ระบบตอนนี้ (Phase 1) ครบสำหรับ **ธุรกิจบริการ/ขนส่ง**: GL · ขาย QO→IV→BN→RV · ซื้อ PO→AP→PV · เช็ค · เงินสดย่อย · ธนาคาร · VAT/WHT/ภ.พ.30/ภ.ง.ด.3/53 · ทรัพย์สิน · ปิดงวด · API/MCP
- เทียบ Express 12 ระบบ: มีครบหรือเกือบครบ **8 ระบบ** · ขาดหลัก **1 ระบบ** คือ **สินค้าคงคลัง** (ซึ่งทำให้ "จัดซื้อรับสินค้า" "ขาย/จอง/จัดจำหน่าย" "วิเคราะห์ซื้อ/ขาย" ไม่ครบไปด้วย) · Express มี POS เป็น add-on
- เพื่อ "รองรับทุกธุรกิจ" ต้องเพิ่ม **12 โมดูล** (หัวข้อ 4) · โมดูลที่ปลดล็อกธุรกิจได้มากที่สุดคือ **สต็อก → หลายสกุลเงิน → สาขา → โครงการ** · ธุรกิจ software ต้องการ **สัญญา/รายได้รับล่วงหน้า (TFRS 15)** และ **ภาษีจ่ายต่างประเทศ (ภ.พ.36 / ภ.ง.ด.54)** เป็นพิเศษ
- แนะนำแบ่ง 3 ช่วง (หัวข้อ 6): **2A** สต็อก + หลายสกุลเงิน + สาขา + software · **2B** โครงการ + เงินเดือน + POS · **2C** การผลิต + ฝากขาย + สัญญาเช่า

## 4. โมดูลที่ต้องเพิ่ม

แต่ละโมดูล: สิ่งที่ต้องทำ · เทียบ Express · เรื่องที่ต้องให้คนตัดสิน

### 4.1 สินค้าคงคลัง (INV) — ปลดล็อก 6 ธุรกิจ · Express ระบบ 3
- คลังหลายแห่ง · หน่วยนับหลายหน่วย (ซื้อเป็นลัง ขายเป็นชิ้น) · รับ/เบิก/โอน/ปรับยอด/ตรวจนับ
- ต้นทุนถัวเฉลี่ย (AVCO) ก่อน · FIFO เป็นทางเลือก (FR-IN-08) · ห้ามติดลบ (เปิดได้ต่อคลัง)
- perpetual (ตัดต้นทุนทุกการขาย) หรือ periodic (สรุปสิ้นงวด) ต่อบริษัท (FR-IN-02)
- ใบรับสินค้า GR แยกจากบิล (FR-PU-09) · สินค้าชุด (FR-IN-06) · บาร์โค้ด Serial/Lot (FR-IN-07) · จุดสั่งซื้อ (FR-IN-05) · landed cost ค่าขนส่ง/อากรเข้าต้นทุน (FR-IN-04)
- รายงาน: สต็อกการ์ด · มูลค่าคงเหลือ · เคลื่อนไหว · ถึงจุดสั่งซื้อ · **รายงานสินค้าและวัตถุดิบ (แบบ สรรพากร ม.87(3))**
- **[ผู้สอบบัญชี]** วิธีต้นทุนตั้งต้น · การตีราคาสินค้า (ต่ำกว่าทุน/NRV) · สินค้าเสื่อมสภาพ/ทำลาย

### 4.2 Software / สัญญาและรายได้รับล่วงหน้า (CTR) — ธุรกิจ software, เช่า, retainer
- **สัญญาลูกค้า**: รายการบริการในสัญญา (license / implementation / support / subscription) · วันเริ่ม-สิ้นสุด · ต่ออายุอัตโนมัติ
- **ออกใบแจ้งหนี้ตามรอบ** (รายเดือน/ปี) อัตโนมัติจากสัญญา · คิดตามการใช้งาน (usage-based) รับยอดผ่าน API
- **รายได้รับล่วงหน้า (deferred revenue)**: รับเงินรายปี → ตารางรับรู้รายได้รายเดือน → JV อัตโนมัติทุกสิ้นงวด (เหมือนค่าเสื่อม)
- **แยกภาระที่ต้องปฏิบัติ (performance obligations)** ตาม TFRS 15: license รับรู้ ณ จุดเวลา · subscription/support ตามช่วงเวลา · implementation ตามความสำเร็จของงาน
- ตัวชี้วัด: MRR / ARR · ลูกค้าเลิกใช้ (churn) · รายได้ที่จะรับรู้ในอนาคต (backlog)
- ต่อกับ billing ภายนอก (Stripe, Omise, App Store) ผ่าน API ที่มีอยู่
- **[ผู้สอบบัญชี]** การปันส่วนราคาให้แต่ละภาระ (standalone selling price) · จุดภาษีขาย VAT ของ subscription (ตอนออกใบแจ้งหนี้ หรือรับเงิน ตาม ม.78/1 ที่ใช้อยู่)

### 4.3 ภาษีเฉพาะธุรกิจ software / จ่ายต่างประเทศ (TX-INTL)
- **ภ.พ.36**: นำส่ง VAT แทนผู้ให้บริการต่างประเทศ (ค่า cloud, SaaS, โฆษณา, license จากต่างประเทศ) แล้วขอคืนเป็นภาษีซื้อเดือนถัดไป
- **ภ.ง.ด.54**: หักภาษี ณ ที่จ่ายจากค่าลิขสิทธิ์/ค่าบริการที่จ่ายต่างประเทศ · อัตราตามอนุสัญญาภาษีซ้อนรายประเทศ (เป็นตาราง config)
- **สินทรัพย์ไม่มีตัวตน**: ต้นทุนพัฒนาซอฟต์แวร์ที่บันทึกเป็นสินทรัพย์ + ตัดจำหน่าย (ต่อจากโมดูลทรัพย์สิน)
- **BOI**: แยกรายได้/กำไรส่วนที่ได้รับยกเว้นภาษี (มิติ "กิจการ BOI / ไม่ BOI")
- **[ผู้สอบบัญชี]** ทุกข้อในหัวข้อนี้: เงื่อนไขภ.พ.36 แต่ละกรณี · อัตราตามอนุสัญญา · เกณฑ์ capitalize ต้นทุนพัฒนา · การแยกกำไร BOI

### 4.4 หลายสกุลเงิน (FX) — software, นำเข้า/ส่งออก
- เอกสารขาย/ซื้อ/รับ/จ่ายเป็นสกุลต่างประเทศ (มีคอลัมน์อัตรา `NUMERIC(18,6)` แล้วตาม CLAUDE.md)
- อัตราแลกเปลี่ยนรายวัน (ดึงจากธนาคารแห่งประเทศไทย หรือกรอกเอง)
- กำไร/ขาดทุนจากอัตราแลกเปลี่ยน: เกิดขึ้นจริงตอนรับ/จ่าย · ยังไม่เกิดขึ้น ตอนปรับมูลค่าสิ้นงวด
- VAT 0% สำหรับส่งออก (ม.80/1) + เอกสารประกอบ
- **[ผู้สอบบัญชี]** อัตราที่ใช้ (ซื้อ/ขาย/กลาง ของ ธปท.) · ปรับมูลค่าสิ้นงวดหรือไม่

### 4.5 สาขา (BR) — ค้าปลีก, F&B, บริษัทหลายสาขา
- ตั้งสาขา (รหัส 5 หลัก ตามสรรพากร) · เอกสาร/เลขที่แยกต่อสาขา · `branch_code` มีบนคู่ค้าแล้ว
- ภ.พ.30 แยกยื่นต่อสาขา หรือยื่นรวม (ต้องขออนุมัติกรมสรรพากร) · งบแยกสาขา
- **[ผู้สอบบัญชี]** ยื่นแยก/รวม ต่อบริษัท

### 4.6 โครงการและต้นทุนงาน (PRJ) — รับเหมา, software implement, สำนักงานบัญชี
- โครงการ: งบประมาณ vs จริง ต่อหมวด · ต้นทุนจากบิลซื้อ/ค่าแรง/เบิกของ ผูกโครงการ
- วางบิลตามงวดงาน (progress billing) · เงินประกันผลงานหัก (retention) · เงินล่วงหน้ารับ
- รับรู้รายได้ตามความสำเร็จของงาน (% of completion) + JV ปรับปรุงสิ้นงวด
- **[ผู้สอบบัญชี]** วิธีวัดความสำเร็จ (ต้นทุน / ผลงาน) · การรับรู้ผลขาดทุนที่คาดว่าจะเกิด

### 4.7 เงินเดือน (PAY) — ทุกธุรกิจ (มี flag ปิดไว้แล้ว)
- พนักงาน · เงินเดือน/ค่าล่วงเวลา/เบี้ยเลี้ยง · ภาษีเงินได้หัก ณ ที่จ่าย (อัตราก้าวหน้า) · ประกันสังคม · กองทุนสำรองเลี้ยงชีพ
- ภ.ง.ด.1 รายเดือน · ภ.ง.ด.1ก รายปี · 50 ทวิ พนักงาน · สปส.1-10 · ไฟล์โอนเงินเดือนธนาคาร
- สลิปเงินเดือนส่งพนักงาน · JV เงินเดือนเข้า GL อัตโนมัติ (แยกมิติแผนก/โครงการ)
- **[ผู้สอบบัญชี]** ค่าลดหย่อน/สูตรภาษีที่ตั้งต้น · ข้อมูลส่วนบุคคลพนักงาน (PDPA)

### 4.8 หน้าร้าน POS (POS) — ค้าปลีก, F&B · Express มี Xpress POS
- ขายหน้าร้าน (เว็บ/แท็บเล็ต) · ใบกำกับภาษีอย่างย่อ · ปิดกะ/ส่งเงิน · หลายช่องทางชำระ (เงินสด QR บัตร)
- ตัดสต็อกทันที · สรุปยอดเข้าบัญชีวันละ 1 รายการ
- หรือ: รับข้อมูลจาก POS ภายนอกผ่าน API (ถ้าไม่ทำ POS เอง)
- **[ผู้สอบบัญชี]** ต้องขออนุมัติใช้เครื่อง POS ออกใบกำกับอย่างย่อจากกรมสรรพากร

### 4.9 การผลิต (MFG) — ผลิต, F&B (สูตรอาหาร)
- สูตรการผลิต BOM หลายชั้น · ใบสั่งผลิต · เบิกวัตถุดิบ → งานระหว่างทำ (WIP) → รับสินค้าสำเร็จรูป
- ต้นทุนการผลิต: วัตถุดิบ + ค่าแรง + โสหุ้ยปันส่วน · ผลต่างต้นทุนมาตรฐาน · ของเสีย/ผลพลอยได้
- **[ผู้สอบบัญชี]** เกณฑ์ปันส่วนโสหุ้ย · วิธีต้นทุน (จริง/มาตรฐาน)

### 4.10 ฝากขาย (CSG) — ค้าส่ง/ค้าปลีก · Express ระบบ 9
- ส่งของไปฝากขาย (ยังเป็นสต็อกเรา) · รับรายงานขายจากผู้รับฝาก → ออกใบกำกับ · รับฝากขายของคนอื่น

### 4.11 สัญญาเช่า (LSE) — ผู้เช่า/ผู้ให้เช่า
- ผู้เช่า: สิทธิการใช้สินทรัพย์ + หนี้สินตามสัญญาเช่า (TFRS 16) · ผู้ให้เช่า: ค่าเช่ารับล่วงหน้า (ใช้โมดูล 4.2)
- **[ผู้สอบบัญชี]** บริษัทใช้ TFRS for NPAEs หรือ TFRS เต็ม (ส่วนใหญ่ SME ใช้ NPAEs = ไม่ต้องทำ TFRS 16)

### 4.12 งบประมาณ + e-Tax (BUD, ETAX) — ทุกธุรกิจ
- งบประมาณรายเดือนต่อบัญชี/มิติ + เทียบจริง (FR-GL-10)

## 5. ผลกระทบต่อของที่มีอยู่

- **ผังบัญชีแม่แบบ**: แม่แบบซื้อมาขายไป/DBD ต้องเติมบัญชีของโมดูลใหม่ (สินค้า ต้นทุนขาย WIP รายได้รับล่วงหน้า FX) และให้ผู้สอบบัญชียืนยัน · เพิ่มแม่แบบ "ซอฟต์แวร์/IT" และ "ผลิต"
- **มาตรฐานรายงาน**: บริษัทเลือกได้ TFRS for NPAEs (ค่าตั้งต้น SME) หรือ TFRS เต็ม → บางโมดูล (TFRS 15 เต็ม, TFRS 16) เปิดเฉพาะ TFRS เต็ม **[ผู้สอบบัญชี]**
- **กระทบยอด (ScreenReconReport)**: เพิ่มจุดตรวจ สต็อก↔GL 1200100 · รายได้รับล่วงหน้า↔GL · WIP↔GL · ภ.พ.36↔GL
- **ปิดงวด**: เพิ่มขั้น รับรู้รายได้ล่วงหน้า · ปรับมูลค่า FX · ตัดต้นทุน periodic · ค่าเสื่อมสินทรัพย์ไม่มีตัวตน
- **แบบร่าง UI**: ต้องออกแบบหน้าใหม่ราว 35–45 หน้า (ประเมินจากจำนวนหน้าต่อโมดูลของ Phase 1)
