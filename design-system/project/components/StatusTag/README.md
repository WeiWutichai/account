# StatusTag

ป้ายสถานะชุดเดียวทั้งระบบ มี 4 ความหมาย (สำเร็จ / รอ / ผิดพลาด / ข้อมูล) + กลาง + แหล่งที่มา สีต้องมาคู่กับคำเสมอ

- สูง 24 px, ตัวอักษร 13 px น้ำหนัก 500, มุม `radius-sm`, padding แนวนอน `space-03`
- สีจาก `status-*-bg` / `status-*-text` เท่านั้น ห้ามกำหนดสีเอง
- จุดนำหน้าเฉพาะ 4 ความหมายสถานะ (ช่วยคนตาบอดสีแยกจากข้อความได้) tag กลางและแหล่งที่มาไม่มีจุด
- คำสถานะมาตรฐาน: ร่าง · รออนุมัติ · ลงบัญชีแล้ว · ชำระบางส่วน · ชำระแล้ว · เกินกำหนด N วัน · ยกเลิก
- ผู้ใช้ส่ง: `kind` (success|warning|error|info|neutral|source), `label`
