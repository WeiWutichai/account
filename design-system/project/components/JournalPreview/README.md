# JournalPreview

แผง "ตัวอย่างการลงบัญชี" แสดง Dr/Cr ที่ Posting Engine จะสร้าง ก่อนผู้ใช้กดอนุมัติ

- ใช้ Carbon StructuredList สีกลาง (พื้น `bg-layer-1`) ไม่ใช้พื้นสีเข้ม
- บรรทัด Cr เยื้องขวา 16 px ตามธรรมเนียมบัญชี; ค่าศูนย์เป็นช่องว่าง
- บรรทัดที่เกิดจากโมดูลเสริม (ต้นทุนขาย/สต๊อก) แสดงสี `text-secondary` พร้อมหมายเหตุ
- ท้ายแผงบอกชื่อสูตรที่ใช้ และ "คำนวณใหม่ทุกครั้งที่แก้เอกสาร · ลงจริงเมื่ออนุมัติ"
- แสดงเฉพาะผู้ที่มีสิทธิ์ `journal:read`
- ผู้ใช้ส่ง: `lines` [{account, name, debit, credit, muted}], `ruleName`
